# Forge Engine

Installers for Forge Engine. Download the newest version from **[Releases](https://github.com/karn-legendstar/forge2-releases/releases/latest)**. Once installed, Forge updates itself.

## Windows
1. Download `Forge-Engine-Setup-X.Y.Z.exe` and run it.
2. If Windows SmartScreen warns (the installer is not signed yet), choose **More info → Run anyway**.
3. Forge opens. Sign in with your work account.

When a new version is ready, Forge shows **Restart to update** at the top.

## Mac
1. Download the `.dmg` for your Mac: `arm64` (Apple silicon: M1, M2, M3…) or `x64` (Intel).
2. Open it and drag **Forge Engine** onto **Applications**.
3. The first time, right-click Forge Engine in Applications → **Open** (or System Settings → Privacy & Security → **Open Anyway**). If macOS says the app is damaged, run once in Terminal: `xattr -cr "/Applications/Forge Engine.app"`

When a new version is available, Forge shows **Version X available**; download it and drag it onto Applications again. Your projects are kept.

## Coding agents
In Forge, open **Project → Agents → Use Forge in a project** and copy the entry for Claude Code or Codex.
